# Button

Buttons der Config sind lange Pillen; der Speichern-Knopf meldet das Ergebnis selbst.

- Radius `r-pill`, Innenabstand 10 × 22 px, Text 14 px/600.
- Haupt: `cfg-prim` / `cfg-prim-ink`. Neben: Geister-Button `cfg-panel` mit Rahmen `cfg-line`. Löschen: Text `crit`, rötlicher Rahmen.
- Speichern: 2 s grün mit „Gespeichert“ (kurzes Pulsieren, 0,2 s), bei Fehler rot mit „Fehler“, danach zurück. Kurzbefehl Strg/⌘ + S.
