# Card

Karten gliedern die Config in Bereiche; sie stehen in Masonry-Spalten.

- Fläche `cfg-panel`, Radius `r-l`, Schatten `shadow-cfg`, Innenabstand 20 × 22 px.
- Überschrift `cfg-title`, Hinweis `cfg-note` in `cfg-muted`, Felder als Pillen mit Rahmen `cfg-line`.
- Kein eigener Speichern-Knopf je Karte: alles läuft über die gemeinsame Speicherleiste.
