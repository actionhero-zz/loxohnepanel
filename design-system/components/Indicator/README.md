# Indicator

Indikatoren zeigen Status und Anzahl: Statuspunkt, Zahlenbadge, Hero-Symbol – immer abgerundete Quadrate.

- Radius immer `radius-round` (32 %). Keine Kreise – Kreise sind Bedienelementen vorbehalten.
- Zahlenbadge: Fläche `dot-*` des Tabs, Zahl in `ink`, Font `num` 12 px/600. Bleibt quadratisch, wächst bei zwei Stellen nur so weit wie nötig.
- Statuspunkt 8 px; Farbe `dot-*`, `good` oder `crit` – immer neben einem Wort.
