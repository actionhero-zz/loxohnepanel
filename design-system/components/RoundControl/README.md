# RoundControl

Bedienelemente bleiben Kreise: Mini-Buttons, Schalterknopf, Regler-Daumen, Player, Zurück, Schließen.

- Radius `radius-control` (50 %). Mindestens 44 px Tippfläche.
- Schalter: Bahn `r-pill`, aus `ink-2`, an `dot-*`; Knopf `tile`.
- Diese Elemente nie in Quadrate umwandeln – die Form unterscheidet „bedienen“ von „anzeigen“.
