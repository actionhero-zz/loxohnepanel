# TabBar

Die Tableiste sitzt oben auf dem Rahmen; je Tab ein Symbol, der aktive Tab ist eine Fläche.

- Höhe `tabbar-h`, auf `bezel`. Inaktiv `tab-idle`, aktiv Fläche `tab-active` mit `tab-active-ink` und kleinem Punkt darunter.
- Tabs teilen die Breite gleichmäßig (max. 64 px). Auf Tablets optional mit Beschriftung.
- Die Infoleiste (Fenster offen, Alarme) liegt auf Tablets unten am Bildschirmrand, die Tableiste bleibt oben.
